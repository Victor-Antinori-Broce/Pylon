Impacto:
  • Backend ya no fuerza monolitos para kons que declaran admin.views
  • Kons sin admin.views siguen funcionando con fallback legacy
  • Esports ya no reporta hasCustomView:true incorrectamente

┌─────────────────────────────────────────────────────────────────────────────┐
│  DECISIONES TOMADAS                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

Filosofía aplicada: "Django Admin pero más dinámico"
  • CRM: Puro DataExplorer. Kanban básico con groupBy:"status" (suficiente
    para operar). NO dashboards, NO timelines (eso es producto).
  • Agile: Puro DataExplorer en grids. Board kanban eliminado del admin
    (es app de producto, debe ir al grimoire).
  • Conta: Hybrid. Grids para listados + custom forms para lógica de negocio
    (partida doble, reportes) que el DataExplorer no puede expresar.
